사이트 소개

가벼운 이미지는 사진의 용량을 줄이고 파일 형식과 픽셀 크기를 바꾸기 위한 무료 브라우저 도구입니다. 별도 계정이나 서버 업로드 없이 사용할 수 있도록 설계했습니다. 압축 결과는 기기의 브라우저에서 생성됩니다.

참고: 압축률과 결과 화질은 원본 이미지, 출력 형식, 브라우저 구현에 따라 달라집니다.

사용법

  1. 이미지 선택 버튼으로 JPG, PNG 또는 WebP 파일을 선택합니다.
  2. 화질과 출력 형식을 고릅니다. 필요하면 가로 또는 세로 크기를 입력합니다.
  3. ‘이미지 압축하기’를 누르고 결과의 용량·절감률을 확인합니다.
  4. 각 결과의 다운로드 버튼을 눌러 저장합니다. iPhone에서는 브라우저의 다운로드 목록 또는 공유 메뉴에서 저장 위치를 확인할 수 있습니다.

파일 및 브라우저 제한

  • 파일당 최대 20MB, 출력 크기는 한 변 최대 12,000px로 제한합니다. 기기의 메모리 상황에 따라 더 작은 이미지도 실패할 수 있습니다.
  • 애니메이션 이미지, SVG, GIF, HEIC/HEIF, AVIF 등은 지원하지 않습니다. 정지 이미지 JPG·PNG·WebP를 사용하세요.
  • PNG는 무손실 형식이므로 화질 슬라이더가 적용되지 않고, 결과가 원본보다 커질 수도 있습니다.
  • WebP 인코딩은 브라우저 지원 여부에 따라 달라집니다. 요청한 형식으로 만들 수 없으면 오류를 표시하며, 다른 형식으로 몰래 바꾸지 않습니다.

개인정보처리방침

시행일: 2026년 10월 12일

1. 이미지 파일 처리

사용자가 선택한 이미지 파일은 이 페이지의 JavaScript와 브라우저 Canvas 기능으로 기기 내에서 처리합니다. 이 사이트 자체는 이미지 파일을 별도 서버로 업로드하거나 저장하지 않습니다. 결과 파일도 사용자가 다운로드할 때 기기에서 저장합니다.

2. 자동 수집 및 저장

이 단일 HTML 파일은 자체 계정, 데이터베이스, 쿠키 기반 분석 기능을 포함하지 않습니다. 다만 사이트를 호스팅하거나 향후 분석·광고 서비스를 연결하면 해당 제공자가 접속 로그, 쿠키 또는 광고 식별자 등 정보를 처리할 수 있습니다. 실제 서비스에 연결하기 전 각 제공자의 정책을 확인하고 이 방침을 갱신해야 합니다.

3. 제3자 서비스

현재 광고 코드는 포함되어 있지 않습니다. 광고나 분석 도구를 추가하면 해당 서비스의 개인정보 처리 방식과 이용 목적을 별도로 고지합니다.

자주 묻는 질문

압축했는데 용량이 더 커졌어요.

작은 이미지나 이미 최적화된 이미지, PNG는 변환 후 더 커질 수 있습니다. 결과의 실제 파일 크기를 확인하고 형식이나 화질을 바꿔 보세요.

JPEG로 바꾸면 투명 배경은 어떻게 되나요?

JPEG는 투명도를 지원하지 않습니다. 투명한 영역은 위에서 고른 배경색으로 채워집니다. 기본값은 흰색입니다.

이미지 파일이 외부로 전송되나요?

이 페이지의 압축 기능은 파일을 서버에 업로드하지 않습니다. 단, 배포 후 별도의 광고·분석 스크립트를 추가하면 그 스크립트의 동작은 별도로 확인해야 합니다.
